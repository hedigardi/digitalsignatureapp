# Digital Signature Platform

The Digital Signature Platform is a web application that enables secure signing of documents using blockchain technology. Users can upload their PDF documents, sign them with their Web3 wallet (e.g., MetaMask), and receive a verifiable transaction link. The application utilizes Pinata to store documents on IPFS (InterPlanetary File System) and generates a URL that can be used to verify the signature via Etherscan.

## Features

- Authenticate using a Web3 wallet.
- Upload and sign PDF documents.
- Store documents on IPFS via Pinata.
- Generate a verification link for easy signature verification.
